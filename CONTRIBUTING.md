# Contributing to Ajora

Welcome! We're excited that you're interested in contributing to Ajora.

Ajora is an open-source project and we actively participate in **Drips Wave** programs to reward our contributors for their hard work.

## Drips Wave Participation 🌊

We use Drips Wave (a recurring bounty cycle) to accelerate our development. By resolving specific issues, you can earn Points that translate into rewards at the end of the Wave cycle.

### How to get involved

1. **Find an Issue**: Look for open issues in this repository that have been added to an active Wave Program. These are typically marked with a specific label (e.g., `Stellar Wave` or `Drips Wave`).
2. **Check the Complexity**: Each Wave issue is assigned a complexity level which dictates the Points you can earn:
   - **Trivial** (100 Points): Minor bug fixes, typos, or simple documentation updates.
   - **Medium** (150 Points): Standard features or more involved bug fixes.
   - **High** (200 Points): Complex features, refactors, or new major integrations.
3. **Apply & Get Assigned**: If you find an issue you want to work on, express your interest. A maintainer will review your application based on your GitHub Code Metrics and assign the issue to you.
4. **Fix & Merge**: Fork the repository, create a branch, write your fix, and open a Pull Request (PR). Make sure your PR explicitly links to the issue it resolves (e.g., `Resolves #123`).
5. **Get Rewarded**: Once your PR is reviewed and merged, the issue will be marked as resolved. You'll earn the allocated Points, which will be distributed as rewards at the end of the Wave cycle.

**Important**: Issues must be resolved *before the Wave ends* to receive your points for that cycle. Please ensure you have the capacity to complete the task within the sprint timeframe before applying.

## Local Development Setup

Please refer to the `README.md` Quickstart section to set up the different parts of our monorepo:
- **Contracts**: Soroban CLI setup in `./contracts`
- **App**: Next.js mini-app frontend in `./app`
- **Indexer**: Horizon/Mercury setup in `./indexer`
- **Push service**: Node.js backend in `./push`

## Pull Request Guidelines

- Ensure your code follows the existing style and conventions.
- Write tests for your changes where applicable (Soroban CLI tests for contracts, etc.).
- When opening a PR, use the provided Pull Request template and fill in all the required details.
- Always link the PR to the issue you are fixing.

## Code of Conduct

Be respectful, constructive, and collaborative. We are building this project together!
